# School Intelligence OS

A personal school-improvement platform for an Assistant Headteacher (Teaching & Learning and English), Reception to Year 6.

**Status:** Sprint 0 (architecture) complete. No application code yet.

- `docs/sprint-0-blueprint.html` — navigation map, system architecture, database relationships, proposed Command Centre, module connections, Sprint 1 acceptance criteria, roadmap and decisions. Open it in a browser.

## Ground rules

- Fictional demonstration data only until the school's data protection officer, IT team and headteacher approve otherwise.
- No pupil names and no safeguarding records are stored in this application.
- No teacher scores or rankings.
- AI output is a suggestion that a person approves or dismisses.
- Nothing is deployed publicly without approval.

## Planned stack (Sprint 1)

Next.js, React, TypeScript, Tailwind with shadcn/ui, PostgreSQL via Drizzle (migrations), Recharts, React Flow, Vitest and Playwright. School Microsoft 365 sign-in is added once IT approves; Sprint 1 uses a local demonstration login behind the same interface.
